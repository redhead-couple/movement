# Media provenance and attribution

Movement Timeline Studio separates the license for its source code from the
provenance and permission records for bundled media.

The repository's [`LICENSE`](LICENSE) describes the MIT license used for source
code and accompanying software documentation. It must not be read as placing
the bundled images, narration, photographs, icons, or other media under MIT.
Those assets are documented separately in
[`distribution/media-provenance.json`](distribution/media-provenance.json).

The machine-readable manifest is the canonical inventory. Its selectors cover
every media file in the current Public Alpha candidate, and the verification
tool rejects missing, extra, overlapping, private, or incorrectly MIT-labelled
records.

## Example images

Ezra created all images in the current public `examples/` tree for this
project. Most were generated using ChatGPT and a smaller number using Gemini.
They were not sourced from stock-image sites, third-party image sites, other
people's photographs, or external media collections.

Unless the exact service is identified in the manifest, the accurate source
description is:

> Created by Ezra using AI image-generation tools (ChatGPT or Gemini); exact
> tool for this file not individually recorded.

The filename `ChatGPT Image Jul 20, 2026, 04_22_12 AM.png` identifies ChatGPT
as the tool for that file. The filename is repository evidence for the service,
but does not establish an exact model, prompt, or broader legal conclusion.

No current public example image is based on or derived from a recognizable real
person. The illustrated red-haired presenter is an original fictional character
from Ezra's imagination, not a real person's likeness. This statement applies
only to the current public media inventory and not to private project data.

AI service terms continue to apply. Recording an AI tool does not imply provider
endorsement, does not transfer provider trademarks, and does not make a legal
claim about copyrightability. These images are not offered under the repository
MIT license.

media. New public media must receive a provenance record before the verifier
